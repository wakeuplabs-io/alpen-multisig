# Evolution archive

**Audience:** Engineers tracing what shipped after a feature merged.

Files here are **archived post-merge summaries** — narrative closure for delivered features. They are **not** SSOT for current behavior.

## Authority order

| Need | Read |
|------|------|
| Current behavior | [`specs/<feature>.md`](../../specs/) |
| PRD compliance (Admin Wallet) | [`specs/admin-wallet-prd-compliance.md`](../../specs/admin-wallet-prd-compliance.md) |
| What changed when it landed | This folder (historical) |

If an evolution doc contradicts a current spec, the spec wins — see [`specs/README.md`](../../specs/README.md).

## Naming

Files are dated or named after the feature slug (e.g. `2026-06-03-admin-wallet-balance-ux.md`). Pair with the matching [`archive/features/`](../features/) subdirectory and functional spec for full context.

See also [`archive/README.md`](../README.md).
