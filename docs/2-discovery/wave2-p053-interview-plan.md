# P-053 — Signer interview plan (Wave 2)

**Goal:** Recruit 5–8 multisig signers for 45-minute sessions on proposal review, signing, and broadcast confidence.

## Recruitment

- Strata administrators (2–3)
- Sequencer managers (1–2)
- Security council / payout admin when ASM roles land (1–2)

## Script outline

1. Walk through create → preview → sign → broadcast happy path.
2. Ask: what would you verify on-device vs on-screen?
3. Digest-verification usability probe (see `wave2-p053-digest-usability.md`).
4. Tabletop: coordinator down after quorum — export hex path (US-H5).

- Findings doc in `docs/2-discovery/` (post interviews)
- Feed P-006 verify-gate copy and Track E E2E matrix
